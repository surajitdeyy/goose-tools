# goose-tools

Community tools and extensions for the [goose](https://github.com/aaif-goose/goose) AI agent.

## Extensions

### [diff-extension](diff-extension/)

Unified diff display for goose Desktop. Renders visual diffs with syntax highlighting inline in the chat window when goose uses the `edit` tool.

- **Install**: `./diff-extension/scripts/install.sh [path-to-goose-repo]`
- **Uninstall**: `./diff-extension/scripts/uninstall.sh [path-to-goose-repo]`
- **Zero token impact** — purely a client-side UI change
